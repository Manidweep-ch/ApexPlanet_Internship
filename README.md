This project is created as part of my ApexPlanet Web Development Internship.

## Software and Tools Installed
- XAMPP
- PHP
- MySQL
- Git
- VS Code

## What I Did

- Created a project folder inside htdocs
- Created a basic PHP file using index.php
- Tested the project using localhost
- Initialized Git in the project folder
- Connected the project to GitHub and pushed the files

## Project Files
